Finance-Analytics
> A 7-day practical journey connecting Economics + Statistics + Mathematics + Finance + Data Analytics.
> The learning is project-based, with each stage combining concepts, practice, analysis and Jupyter Notebook projects.
About: This repository documents my 7-day Finance Analytics journey, designed to strengthen my foundation in Financial Analysis and FP&A (Financial Planning & Analysis). With an academic background in Economics and a foundation in Economics, Statistics, and Mathematics, this journey focuses on applying quantitative and economic concepts to real-world financial and business problems.
Objectives:
 - Strengthen mathematical and statistical foundations for finance
 - Apply economics to real-world business decisions
 - Build financial analysis skills
 - Understand budgeting, forecasting and variance analysis
 - Develop practical FP&A knowledge
 - Apply Python and SQL to financial and business data
 - Develop data-driven business interpretation skills
 - Build portfolio-ready finance projects
Tools & Technologies
Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, SQL, Excel, Git & GitHub
Core Areas
Mathematics • Economics • Statistics • Financial Analysis • FP&A • Business Analytics • Financial Modelling • Budgeting • Forecasting • Data-Driven Decision Making
Learning Approach
Learn → Practice → Analyze → Build → Interpret → Document
The focus is not only on performing calculations, but on understanding the business meaning behind the numbers:
> What happened? → Why did it happen? → What does it mean? → What should the business do?
Background: This journey builds on my Economics graduation and my academic foundation in Economics, Statistics and Mathematics, while expanding my skills toward Finance, FP&A and Data Analytics.
Goal: To build a strong bridge between: Economics + Statistics + Mathematics + Finance + Data Analytics
and develop practical skills for Financial Analyst and FP&A-oriented roles through hands-on learning and project-based analysis.
